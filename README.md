1. App idea: StudyBuddy is an application designed to help students find study partners and create study groups. It aims to encourage collaboration, improve learning experiences, and help students organize their academic activities.

2. User Stories:
-Feature 1:
User Story 1: As a university student, I want to create an account with my course details, so that I can be matched with classmates who are studying the same subjects.
User Story 2: As a university student, I want to log in quickly to my account, so that I can access and join study groups without re-entering my information every time.

-Feature 2:
User Story 1: As a student, I want to edit my bio, courses, and preferred study mode so that potential study partners can decide whether we are a good match.
User Story 2: As a student, I want to add and remove weekly availability slots on my profile so that potential study partners can see when I’m free.

-Feature 3:
User Story 1: As a student, I want to search potential study partners based on specific academic courses, so that I can connect with peers who are studying the same material as me.
User Story 2: As a student, I want to view a study partner's profile card from the search results, so that I can decide if we are a good match before connecting.

-Feature 4:
User Story 1: As a student, I want to create a study group for a specific course so that I can collaborate with classmates.
User Story 2: As a student, I want to add a description to my study group so that other students know its purpose.   

-Feature 5:
User Story 1: As a student, I want to browse available study groups so that I can find one that suits me.
User Story 2: As a student, I want to join a study group so that I can study with others.

-Feature 6:
User Story 1: As a student, I want to create and view my study schedule so that I can organize my study sessions.
User Story 2: As a student, I want to set reminders for my study sessions so that I don't miss them.

-Feature 7:
User Story 1: As a student in a study group, I want to receive a reminder notification before a scheduled study session starts, so that I do not forget to attend and can prepare my materials on time.
User Story 2: As a student looking for people to study with, I want to receive a notification when someone invites me to join a study group, so that I can quickly accept or decline the invitation and begin collaborating with my peers.


3. Wireframes:
Home Page & Dashboard: Main navigation and upcoming sessions view.
Login & Registration: Form screens with validation states and toggles.
Student Profile: Profile view and Edit Profile configuration modal.
Search Study Partners: Filter layout and partner profile cards.
Create Study Group: Input form for group details and capacity.
Join Study Groups: Browse list with group cards and status buttons.
Schedule & Reminders: Calendar week view and reminder configuration settings.
Notifications: Notification center layout with unread status indicators and action buttons.
